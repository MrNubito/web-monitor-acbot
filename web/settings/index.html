ACBot Android APK Monitor

Monitor the ACBot APK running inside an emulator. Each instance gets a Discord status panel with observed attacks, recent logs and screenshots. Optional Android Autostart can open an instance when Monitor starts, or run on demand with Start now. Monitoring alerts never restart apps.

No recent logs may mean the APK is waiting, paused or blocked. Attack counts start when the monitor attaches and are not ACBot's official totals. Two consecutive unhealthy checks are required before an alert.

Uses the ADB executable selected in the AutoClash tab. Save changes and start the bot to begin monitoring.

Options
Detects the Clash of Clans Connection lost popup and restarts CoC automatically.
Seconds to wait before Stop and before Start after an ADB screencap error. Default: 8 and 5.
Automatically cleans the control-screenshots folder. Default: 24 hours or 1500 MB.

Setup guide

              
Create and connect your Discord bot

              
Follow these steps on any PC where you want to run Discord Log Monitor.

            

          


          

            

              
1. Create the Discord bot

              
    
                
  1. Open Discord Developer Portal.
    2. 
                
  2. Click New Application.
    3. 
                
  3. Name it Discord Log Monitor.
    4. 
                
  4. Go to Bot.
    5. 
                
  5. Copy or reset the bot token.
    6. 
              

              
Never share the bot token. If it leaks, reset it.

            


            

              
2. Invite it to your server

              
    
                
  1. Go to OAuth2 > URL Generator.
    2. 
                
  2. Select the bot scope.
    3. 
                
  3. Select the required permissions.
    4. 
                
  4. Open the generated URL.
    5. 
                
  5. Choose your server and authorize the bot.
    6. 
              

            


            

              
3. Required permissions

              
    
                
  • View Channel
    • 
                
  • Send Messages
    • 
                
  • Embed Links
    • 
                
  • Attach Files
    • 
                
  • Create Public Threads
    • 
                
  • Send Messages in Threads
    • 
                
  • Mention Everyone
    • 
                
  • Manage Channels
    • 
                
  • Read Message History
    • 
              

            


            

              
4. Create channels

              
Create one Discord channel per log, for example:

              
ld9
bluestacks

              
The bot can rename them automatically:

              
green circle = running
red circle = stopped

            


            

              
5. Get channel IDs

              
    
                
  1. Open Discord settings.
    2. 
                
  2. Go to Advanced.
    3. 
                
  3. Enable Developer Mode.
    4. 
                
  4. Right-click a channel.
    5. 
                
  5. Click Copy Channel ID.
    6. 
              

            


            

              
6. Configure this app

              
    
                
  • Discord: bot token and fallback channel.
    • 
                
  • Logs: channel IDs and log folders.
    • 
                
  • AutoClash: panel channel, exe list, and ADB.
    • 
                
  • Options: intervals and line limits.
    • 
              

            


            

              
7. AutoClash panel

              
    
                
  • Set Enabled to true.
    • 
                
  • Paste the panel channel ID.
    • 
                
  • Add every AutoClash exe manually.
    • 
                
  • Choose PRO or BASIC for each exe.
    • 
                
  • Set the ADB device port for each emulator.
    • 
              

            


            

              
8. Recommended options

              
Check every: 5
Alert after: 180
Read lines: 10
Show lines: 20
Live log thread: true
Live interval: 10
Restart on stop: Off or Auto start

            


            

              
9. Start the bot

              
    
                
  • Click Save.
    • 
                
  • Click Start bot.
    • 
                
  • Check the app console.
    • 
                
  • Check Discord for log embeds and the AutoClash panel.
    • 
              

            


            

              
10. Troubleshooting

              
    
                
  • If the bot does not start, check the console panel.
    • 
                
  • If channels do not rename, check Manage Channels permission.
    • 
                
  • If everyone is not notified, check Mention Everyone permission.
    • 
                
  • If no lines appear, confirm the folder contains `.txt` logs.
    • 
                
  • If stats fail, check the exe path, ADB path, ADB device, and Attach Files permission.
    •
